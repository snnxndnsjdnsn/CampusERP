## Deliberate divergences

| MySQL | PostgreSQL | Why |
|---|---|---|
| `AUTO_INCREMENT` | `GENERATED BY DEFAULT AS IDENTITY` | the sequence is resynced in 015 |
| `TINYINT/SMALLINT/INT/BIGINT UNSIGNED` | domains `u8`/`u16`/`u32`/`u64` | the range is checked by the domain; the identity columns use the plain integer type |
| `ENUM(...)` | `text` + named `CHECK (col IN (...))` | the check keeps the value list |
| `BOOLEAN` | `boolean` | - |
| `TIMESTAMP`, `DATETIME` | `timestamptz` | the source assumes a UTC session |
| `YEAR` | domain `u_year` | 1901-2155 |
| `JSON` | `jsonb` | the key order is not preserved |
| `VARBINARY` | `bytea` | - |
| `ON UPDATE CURRENT_TIMESTAMP` | `BEFORE UPDATE` trigger `sims_touch_updated_at()` | the trigger only bumps the column when the row really changed |
| `INSERT IGNORE` | `ON CONFLICT DO NOTHING` | - |
| `REGEXP` | `~` | - |
| `DATEDIFF`, `TIMESTAMPDIFF`, `IFNULL`, `DATE()` | `date - date`, `age()`, `COALESCE`, `CAST(.. AS date)` | - |
| `SIGNAL SQLSTATE '45000'`, `<=>` | `RAISE EXCEPTION .. ERRCODE '45000'`, `IS NOT DISTINCT FROM` | the triggers are ported to PL/pgSQL |
