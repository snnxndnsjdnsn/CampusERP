# Role and permission matrix

Generated by `node tools/validate/role_matrix.mjs` from the live database. Do not edit by hand.

A cell lists the actions the role is granted anywhere in that access module: **C**reate, **R**ead, **U**pdate, **D**elete, **A**pprove, **V**erify, **E**xport, confi**G**ure. A grant applies at the scope of the user's role assignment (self, programme, department, campus, institution or global); some resources inside a module (for example `FEES.FEE_REFUND`) are granted separately, see the per-role list in the database. Sensitive resources need their specific grant: `ALL` is not enough.

## Scope types

A role is assigned at one scope type.  The scope of the assignment decides how far a grant reaches.

|---|---|---|---|
| `GLOBAL` | the whole installation | 4 | 3 |

| `CAMPUS` | one campus | 4 | 0 |
